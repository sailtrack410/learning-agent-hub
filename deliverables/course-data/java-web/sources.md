# 资料来源

本资料集为课程组原创整理，事实依据优先采用以下官方资料：

1. Jakarta Servlet Specification：https://jakarta.ee/specifications/servlet/
2. MDN HTTP Guide：https://developer.mozilla.org/docs/Web/HTTP
3. Spring Framework Reference：https://docs.spring.io/spring-framework/reference/
4. Spring Boot Reference：https://docs.spring.io/spring-boot/reference/
5. MyBatis 3 Documentation：https://mybatis.org/mybatis-3/
6. Spring Security Reference：https://docs.spring.io/spring-security/reference/
7. JUnit 5 User Guide：https://junit.org/junit5/docs/current/user-guide/
8. Maven Guide：https://maven.apache.org/guides/

代码示例使用教学用途的最小实现，不包含第三方项目源码。
