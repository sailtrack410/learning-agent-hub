# Learning Agent Hub 软件杯教育版用户操作手册

| 项目 | 内容 |
|---|---|
| 文档版本 | V1.0 |
| 编制日期 | 2026-07-19 |
| 适用版本 | 非 Docker 部署、桌面 Web 三端提交版 |
| 首门示范课程 | 《Java Web 应用开发》 |
| 目标读者 | 学生、教师、教育运营管理员、比赛评审人员 |

## 1. 系统组成

比赛提交版包含三个可独立部署的程序模块：

| 模块 | 用途 | 使用者 |
|---|---|---|
| `server` | Spring Boot 后端 API、认证、业务处理和异步任务 | 系统服务，不直接提供操作页面 |
| `employee-web` | 登录后根据教育角色显示学生学习端或教师课程端 | 学生、教师 |
| `admin-web` | 教育运营与 AI 能力治理 | 管理员 |

本文只说明桌面 Web 操作，不包含移动端，也不采用 Docker。访问地址由实际部署人员提供，本文不记录任何真实账号、密码或模型密钥。

## 2. 使用前准备

1. 建议使用当前稳定版 Chrome 或 Edge，浏览器允许 Cookie、JavaScript 和服务器发送事件（SSE）。
2. 确认后端、学生/教师 Web 和管理 Web 均已启动，后端健康检查正常。
3. 学生或教师账号必须已分配 `STUDENT` 或 `TEACHER` 教育角色；管理员账号必须已分配所需后台权限。
4. 使用 AI 资源生成前，管理员应完成默认文本模型配置与连通性测试，课程资料应已成功入库。
5. 如部署环境启用邮箱二次验证，还需准备可接收验证码的邮箱。

## 3. 登录与退出

### 3.1 学生/教师登录

1. 打开学生/教师 Web 入口。
2. 输入登录名和密码，点击“进入平台”。
3. 如果页面提示首次绑定邮箱，填写邮箱并发送验证码，验证后进入系统。
4. 如果页面提示邮箱二次验证，获取并填写验证码后继续登录。
5. 系统根据账号的教育角色自动呈现学生或教师工作区，不需要手工选择身份。

忘记密码时，在登录页切换到密码重置流程，通过已绑定邮箱的验证码设置新密码。验证码短时有效，请勿转发给他人。

### 3.2 管理员登录

1. 打开管理 Web 入口。
2. 输入管理员登录名和密码，点击“登录”。
3. 登录后，左侧导航只显示当前账号拥有权限的模块。

### 3.3 退出

- 学生/教师：进入“个人中心/设置”，点击“退出登录”并确认。
- 管理员：点击页面右上角退出图标。

退出后当前会话立即失效。离开公共电脑前不要只关闭标签页。

## 4. 学生端操作

### 4.1 课程首页与加入课程

1. 进入“课程学习”。首页显示今日任务、课程进度、平均掌握度、待完成练习和推荐资源。
2. 在“全部课程”区域搜索课程，或切换网格/列表视图。
3. 点击一门已发布课程。首次进入时系统建立本人选课关系，课程卡片显示“已加入”。
4. 课程详情左侧列出已发布章节和测验，右侧显示课程导学或当前文章。
5. 文章中的图片、视频和附件按页面提示预览；有权限的附件可下载或在新窗口打开。

学生看不到教师草稿课程和草稿章节。若课程突然不可见，先确认教师是否已发布。

### 4.2 建立学习画像

1. 从左侧导航进入“学习画像”。
2. 阅读对话区当前问题，在输入框填写真实学习情况，点击“提交回答”。
3. 系统依次形成知识基础、学习目标、掌握程度、易错点、认知风格、资源偏好、学习节奏和实践能力等维度。
4. 右侧卡片展示维度结论、置信度、依据和更新时间。
5. 发现结论不准确时，点击该卡片的“纠正结论”，填写补充说明并保存。

画像会形成版本历史，并用于后续路径和资源生成。只填写与学习有关的信息，不要输入手机号、身份证号、账号密码、Token 或 API Key。

### 4.3 查看和推进个性化学习路径

1. 进入课程详情，点击“我的学习路径”。
2. 第一次打开时，系统依据课程知识依赖、当前画像和已有掌握度自动生成首版路径。
3. 在“今日学习”查看当前安排，在“学习路径”查看全部节点，在“推荐资源”查看推荐理由。
4. 点击“学习文章”进入对应章节。只有已解锁节点可以操作。
5. 完成当前内容后点击“标记完成”，系统解锁下一节点并更新进度。
6. 点击“为当前薄弱点生成资源”可进入个性化资源页面。

路径节点状态含“未解锁、待学习、当前学习、已完成”。必须按依赖顺序推进，不能直接跳过锁定节点。

### 4.4 完成课程测验

1. 在课程详情左侧选择已发布测验。
2. 阅读题目并逐题选择答案，可使用“上一题/下一题”检查作答。
3. 最后一题点击“提交测验”，等待系统评分。
4. 结果页展示得分、正误和题目解析；需要时可点击“再测一次”。

提交后系统更新知识点掌握度，并联动画像和学习路径。新路径成为活动版本，旧版本保留用于追溯。

### 4.5 生成个性化学习资源

1. 从课程详情或学习路径进入“个性化资源”。
2. 选择章节和知识点，可填写不超过页面限制的补充学习诉求。
3. 点击生成按钮提交任务。不要连续重复点击；页面会使用幂等请求避免重复任务。
4. 在“生成记录”选择任务，查看任务进度和五个角色的执行状态：画像分析、路径规划、内容生成、练习生成、事实校验。
5. 页面可查看当前步骤实时输出；离开页面后任务仍继续，重新打开会从后端恢复状态。
6. 任务失败时，页面显示失败原因并提供“重新执行”。
7. 任务成功后等待教师审核发布；发布后可按类型查看讲解、思维导图、练习、代码实操和拓展阅读。

模型输出应结合引用阅读。资源仍在审核中时以页面状态为准，不把未发布内容视为课程正式结论。

### 4.6 查看资源并反馈

1. 进入“学习资料”，可按课程、关键词和类型筛选课程文章及个性化资源。
2. 点击资源卡片查看正文、事实校验结论和引用来源。
3. 在资源详情选择“有帮助、太难、太简单、不相关”等反馈，可补充简短说明。
4. 点击“保存反馈”。同一学生对同一资源再次提交会更新原反馈，不产生重复记录。

## 5. 教师端操作

### 5.1 课程列表与新建课程

1. 教师登录后进入“课程管理”。
2. 点击“新建课程”，填写课程编码、名称、授课教师、总学时、简介和状态，可选择课程封面。
3. 建议先保存为“草稿”，完成章节、资料和文章后再发布。
4. 点击课程卡片进入课程工作区。

课程编码必须唯一。课程状态改为“发布”后学生才能在课程目录中查看。

### 5.2 维护课程基础信息

在“基础信息”页维护封面、课程名称、简介、学习目标、先修要求、学时和发布状态，点击“保存基础信息”。页面同时展示课程所有者和协作教师。

只有课程所有者能删除课程。删除操作会影响课程章节、知识库绑定和个性化路径，请确认后再执行。

### 5.3 编排章节、知识点和文章

1. 进入“章节内容”，点击“添加”新建章节。
2. 填写章节名称和简介；可调整章节顺序。
3. 为章节添加知识点编码、名称和简介，点击“保存全部章节”。
4. 保存后点击“写文章”进入独立编辑页。
5. 编辑器支持标题、列表、引用、代码块、链接、表格、图片、视频和附件，完成后选择草稿或发布状态并保存。

知识点编码在同一课程内不能重复，知识依赖不能形成环。学生只能读取已发布章节文章。

### 5.4 上传课程资料并入库

1. 进入“课程资料库”。
2. 先选择资料关联的章节，可进一步勾选知识点。
3. 点击“上传资料”选择讲义、PPT、Word、PDF 或图片等允许文件。
4. 上传后观察解析、分块、向量化进度；成功后显示切片数量。
5. 入库失败时查看页面原因，排除模型、格式或网络问题后点击“重试”。

入库成功的资料才可稳定支持 RAG 检索和生成内容引用。Office 附件预览依赖服务器上的 LibreOffice 命令配置。

### 5.5 查看学情与沟通

- “学情分析”展示课程完成率、平均掌握度、风险学生、薄弱知识点和资源使用情况，可在“风险学生/全部学生”间切换。
- “班级沟通”可打开课程班级群，或向课程学生发起私聊。

教师只能查看本人作为所有者或协作者参与的课程数据。

### 5.6 审核与发布智能资源

1. 进入“生成资源”，点击刷新加载学生任务和资源。
2. 在“生成任务”查看五角色执行轨迹、模型、耗时和失败信息。
3. 在“审核与发布”查看资源正文、事实校验结果和知识库引用。
4. 对待复核资源可执行“修改”“通过”或“拒绝”；拒绝时必须填写原因。
5. 只有校验通过的草稿可点击“发布”。已发布资源可“撤回”。
6. 发布后点击“推送”，选择班级或学生并确认。重复推送会复用原关系，不会生成重复记录。

教师审核时应重点检查结论是否由引用支持、代码能否运行、练习答案是否一致。低置信度内容不得未经核对直接发布。

### 5.7 邀请协作教师

1. 课程所有者在课程工作区点击“邀请教师”。
2. 复制系统生成的邀请链接并通过可信渠道发送给目标教师。
3. 目标教师登录后打开链接并接受邀请。

邀请 7 天内有效且只能接受一次。邀请链接相当于临时授权，不应发布到公共群或公开文档。

## 6. 管理端操作

### 6.1 推荐初始化顺序

首次部署建议按以下顺序配置：

1. “用户与班级”：建立学院、班级和学生/教师账号，确认教育角色。
2. “角色权限”：为管理员分配最小必要的后台角色和权限。
3. “AI 基座”：配置模型供应商和默认文本模型，并完成真实连通性测试。
4. “知识库”：检查全局解析、嵌入和重排模型设置。
5. “AI 助手”：检查助手版本、DAG、模型和知识库绑定，发布可用版本。
6. “内容安全”：设置注入检测、阻断标记和教师复核阈值。
7. “AI 任务”和“运营概览”：确认任务、知识库和系统状态正常。

### 6.2 配置 AI 基座

1. 进入“AI 基座”的“模型配置”。
2. 先添加供应商，填写供应商类型、显示名称、服务地址和 API Key。
3. 点击供应商测试，确认连接成功。
4. 在供应商下添加模型，填写供应商模型 ID、显示名称和模型类型。
5. 使用“新增前测试”或模型列表中的“测试连通性”。
6. 将验证成功的语言模型设为默认文本模型。
7. 在“默认模型”和“测试”页再次核对当前选择。

画像分析、路径规划、内容生成、练习生成和事实校验优先使用后台启用的默认文本模型；未设置可用默认模型时，后端才回退到部署环境 `AGENT_MODEL_*`。API Key 保存后页面只显示“已配置”状态，不会回显原值。

### 6.3 管理 AI 助手

1. 进入“AI 助手”，可搜索、新建、编辑、启用或停用助手。
2. 点击“编排”进入 DAG 页面，维护节点、模型、知识库和流程关系。
3. 保存版本后完成校验与发布，发布版本才会供用户侧使用。
4. 页面提示知识库配置异常时，先修正绑定空间或入库状态，再发布或执行。

### 6.4 管理知识库

1. 进入“知识库”，创建或选择知识空间。
2. 配置或继承 OCR、嵌入和重排模型。
3. 上传文档并观察入库阶段、百分比和失败信息。
4. 对失败文档执行重新入库；成功后使用检索测试核对命中片段。

教师课程资料库负责课程内资料；管理端知识库负责平台级空间和模型治理，两者不要混淆。

### 6.5 内容安全

1. 进入“内容安全”。
2. 按需开启提示词注入检测。
3. 设置教师复核置信度阈值。
4. 添加或删除危险指令标记，保存策略。

多人同时编辑时，若页面提示版本冲突，应刷新后重新核对再保存，不要覆盖他人更新。

### 6.6 用户、班级和管理员权限

- “用户与班级”用于维护学院/班级树、学生与教师资料以及教育角色。
- “角色权限”用于新建后台角色、分配权限、给管理员分配角色。
- “权限点”用于查询当前有效权限；系统内置超级管理员始终拥有全部有效权限，不允许改权或删除。

遵循最小权限原则，不要为了临时操作把所有管理员都设为超级管理员。

### 6.7 任务与运维查看

- “AI 任务”用于按状态查看执行详情、步骤轨迹、失败原因和耗时。
- “文件空间”用于文件对象和清理治理，不用于绕过课程权限直接分发教学资料。
- “审计日志”用于核对已有操作记录；“消息投递”用于查看消息发送状态。

## 7. 常见状态说明

| 对象 | 状态 | 含义 |
|---|---|---|
| 课程/章节 | `DRAFT` / `PUBLISHED` | 草稿仅教师可管理；发布后学生可见 |
| 知识入库 | `PENDING` / `RUNNING` / `SUCCESS` / `FAILED` | 等待、处理中、成功、失败可重试 |
| 学习路径节点 | `LOCKED` / `PENDING` / `IN_PROGRESS` / `COMPLETED` | 未解锁、待学习、当前学习、已完成 |
| 生成任务 | `PENDING` / `RUNNING` / `SUCCEEDED` / `FAILED` | 等待、执行中、成功、失败可重试 |
| 事实校验 | `PASSED` / `NEEDS_REVIEW` / `REJECTED` | 通过、需教师复核、拒绝 |
| 资源发布 | `DRAFT` / `PUBLISHED` / `WITHDRAWN` / `REJECTED` | 草稿、已发布、已撤回、已拒绝 |

## 8. 常见问题处理

| 现象 | 建议处理 |
|---|---|
| 页面提示会话过期或 401 | 重新登录；仍失败时确认 Redis 和后端服务状态 |
| 页面提示无权限或 403 | 确认访问入口、教育角色、管理员权限或教师课程成员关系 |
| 学生看不到课程/章节 | 教师检查课程和章节是否为已发布状态 |
| 学生无法生成路径 | 教师检查课程是否已发布且已配置知识点，学生重新打开路径页 |
| 资源生成立即失败 | 管理员检查默认文本模型、模型连通性、课程资料入库和内容安全阻断信息 |
| 生成中页面刷新 | 重新打开任务；任务状态和步骤从后端恢复，必要时点击刷新 |
| 课程资料入库失败 | 查看失败阶段，检查文件格式、解析服务、嵌入模型和网络后重试 |
| Office 文件不能预览 | 检查服务器 LibreOffice 命令及预览状态；原文件仍按权限下载 |
| 邮箱验证码未收到 | 检查地址、垃圾箱、SMTP 配置和 60 秒发送间隔 |
| 修改内容安全提示版本冲突 | 刷新页面，核对最新策略后重新保存 |

## 9. 安全使用须知

- 不共享账号、密码、邮箱验证码、邀请链接或模型密钥。
- 不在画像回答、资源诉求和反馈中填写身份证号、手机号、密码、Token 等敏感信息。
- 管理员配置 API Key 后不要通过截图、日志或比赛文档传播。
- 教师发布 AI 资源前必须检查引用、答案和代码，不把模型输出直接视为权威教材。
- 公共电脑使用后必须退出登录；发现账号异常应及时停用或重置密码。

## 10. 比赛演示推荐主流程

1. 管理员展示默认模型可用、知识库文档入库成功和内容安全策略。
2. 教师展示课程、章节知识点、课程资料和已发布文章。
3. 学生完成画像回答，打开学习路径并选择薄弱知识点。
4. 学生创建资源任务，展示五角色实时执行轨迹和引用。
5. 教师审核并发布资源，定向推送给学生或班级。
6. 学生查看资源、提交反馈并完成测验。
7. 展示掌握度、画像版本、学习路径和教师学情分析的联动变化。

演示账号与模型凭证应由现场部署人员单独提供，不写入本手册或公开提交目录。

## 11. 核验依据

- 管理端菜单与页面：`admin-web/src/router/index.ts`、`AdminShell.vue` 及对应 Views。
