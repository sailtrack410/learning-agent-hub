## 6. 缺陷修复回归

多智能体长流式调用曾在上游 SSE 异常或不完整结构化输出时失败。修复后的处理边界为：

1. 使用结构化 JSON 请求并校验单一完整 JSON 对象。
2. 对 HTTP 408、429、5xx、网络异常和兼容性 SSE 异常，在角色共享总超时内最多同步降级一次。
3. 流正常结束但为空或 JSON 不完整时，清空不完整正文后最多同步降级一次。
4. 认证、权限、解析和总超时错误不重复请求。
5. 同步结果仍非法时以明确失败类型结束，不保存半截资源。

连续三轮真实模型验收和 33 项定向回归均通过，原缺陷判定为已解决。

## 8. 已知限制

以下限制没有被描述为已通过能力：

- 浏览器验收脚本仍依赖预先存在的画像与资源状态；本报告中的桌面验收有真实浏览器证据，但不是独立空库的一键 E2E。
- 全新数据库需要按部署说明显式初始化首次管理员，并在管理端配置文本模型与 Embedding 模型。
- 本地开发上传桥在中文绝对路径下仍可能受到请求头编码限制；比赛部署应使用独立 ASCII 文件数据路径。
- 部分前端自动化属于源码契约测试，关键点击与异步状态仍以浏览器验收和后端集成测试共同证明。
- MySQL 8.4 实际迁移成功但高于当前 Flyway 版本已验证范围，正式比赛环境固定使用 MySQL 8.0。
