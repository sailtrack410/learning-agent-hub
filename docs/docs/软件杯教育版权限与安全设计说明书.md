# Learning Agent Hub 软件杯教育版权限与安全设计说明书

| 项目 | 内容 |
|---|---|
| 文档版本 | V1.0 |
| 编制日期 | 2026-07-19 |
| 适用版本 | 非 Docker 部署、桌面 Web 三端提交版 |
| 适用范围 | 学生学习端、教师课程端、教育运营管理端及后端 API |

## 1. 设计目标与边界

系统通过身份认证、端路径隔离、角色授权、课程数据范围、本人数据范围和对象状态约束，保证学生、教师与管理员只能访问完成其职责所需的数据和操作。

本文只说明教育主线及其必要运营能力，其他非教育业务权限不在本文展开。前端菜单或按钮隐藏只改善交互，后端校验才是最终安全边界。

## 2. 身份与角色模型

| 主体 | 账号来源 | 角色依据 | 主要入口 |
|---|---|---|---|
| 学生 | `auth_user_account` | `edu_user_role.education_role=STUDENT` | `employee-web` 学习视图 |
| 教师 | `auth_user_account` | `edu_user_role.education_role=TEACHER` | `employee-web` 教师视图 |
| 教育运营管理员 | `admin_user` | `admin_user_role`、`admin_role_permission` | `admin-web` |
| AI 助手 | 系统配置，不是人类登录账号 | 已发布版本、知识绑定和任务上下文 | 后端受控执行 |

学生与教师共用业务用户登录体系，但同一用户当前只对应一个教育角色。管理员使用独立账号表、认证 Provider 和后台路径，不能用管理员会话替代学生或教师身份。

教师课程内再区分：

- `OWNER`：课程所有者，可编辑、删除课程并创建一次性协作邀请。
- `COLLABORATOR`：协作教师，可维护课程、章节、资料、学情和生成资源，不能删除课程或继续邀请教师。

## 3. 后端授权判定链

一次教育请求按以下顺序判定：

1. **认证**：除明确列出的登录、验证码、密码重置、健康检查和接口文档入口外，其余接口要求有效 Spring Security 会话。
2. **端身份隔离**：`/api/admin/**` 只允许管理员身份；`/api/employee/**` 只允许学生或教师业务身份。
3. **管理权限或教育角色**：管理接口校验 RBAC 权限码；业务接口校验 `STUDENT/TEACHER`。
4. **数据范围**：学生限定本人数据；教师限定本人参与管理的课程；课程所有者动作额外校验 `OWNER`。
5. **对象归属与状态**：校验课程是否发布、附件是否属于课程、资源是否已通过审核、路径节点是否可操作等。
6. **参数和幂等约束**：校验字段格式、业务唯一性、幂等键和允许的状态转换。

未登录统一返回 HTTP 401；已登录但身份、角色或权限不符返回 403。部分横向越权查询按“不暴露对象是否存在”的原则返回 404；状态冲突使用 409。

## 4. 教育业务权限矩阵

| 业务动作 | 学生 | 教师 | 管理员 |
|---|---|---|---|
| 查看已发布课程与章节 | 允许 | 仅管理课程 | 不作为主线入口 |
| 加入已发布课程 | 允许本人操作 | 不适用 | 不适用 |
| 创建、编辑、发布课程 | 不允许 | 允许管理课程 | 不适用 |
| 删除课程、邀请协作教师 | 不允许 | 仅课程所有者 | 不适用 |
| 编辑章节文章和上传课程资料 | 不允许 | 允许管理课程 | 不适用 |
| 查看课程附件 | 已发布课程/章节内可读附件 | 仅管理课程附件 | 文件治理权限范围内 |
| 查看或纠正学生画像 | 仅本人 | 学情聚合视图，不直接修改学生画像 | 不作为主线入口 |
| 参加测验并查看结果 | 仅本人 | 查看课程聚合学情 | 不适用 |
| 查看、推进学习路径 | 仅本人 | 查看聚合进度 | 不适用 |
| 创建资源生成任务、查看轨迹、失败重试 | 仅本人任务 | 查看管理课程任务 | 后台查看通用 AI 任务 |
| 修改、审核、发布、撤回生成资源 | 不允许 | 仅管理课程 | 不适用 |
| 定向推送生成资源 | 不允许 | 仅管理课程，且仅已发布资源 | 不适用 |
| 查看资源并提交学习反馈 | 本人生成且已发布，或有权收到的已发布资源 | 查看课程资源 | 不适用 |
| 配置模型、助手、知识库和内容安全 | 不允许 | 不允许 | 按后台权限码允许 |

## 5. 数据范围规则

### 5.1 学生数据范围

- 课程目录只返回已发布课程；选课关系只为当前登录学生创建。
- 画像、画像版本、对话、测验作答、掌握度、学习路径、生成任务和反馈均以当前 `student_user_id` 查询。
- 资源任务详情和 SSE 事件在返回前再次比较任务所属学生；他人任务不返回内容。
- 学生只读取已发布资源，包括本人生成并经教师发布的资源，以及通过本人或班级推送获得的课程资源。
- 课程附件读取时重新检查课程和章节发布状态，不信任正文中携带的附件地址。

### 5.2 教师数据范围

- 教师列表和详情查询通过 `edu_course_teacher` 限定本人参与的课程。
- 课程、资料、学情、学生沟通和生成资源操作均再次校验课程成员关系。
- 删除课程和创建邀请必须是 `OWNER`；邀请令牌有有效期、只能接受一次，数据库只保存摘要。
- 教师只能向当前课程内的学生或班级推送该课程已发布资源。

### 5.3 管理员数据范围

- 管理员先通过独立后台身份校验，再依据角色权限进入功能模块。
- `SUPER_ADMIN` 始终解析为全部当前有效权限；内置超级管理员角色不允许停用、删除或改权。
- 非超级管理员只获得数据库中显式关联的有效权限。
- 管理端治理数据不等于自动取得学生私有画像、作答或会话内容读取权。

## 6. 管理端 RBAC 权限

| 权限码 | 管理能力 | 后端主要路径 |
|---|---|---|
| `ADMIN_AGENT_TASK_MANAGE` | AI 任务查询与治理 | `/api/admin/agent-tasks...` |
| `ADMIN_AGENT_MANAGE` | AI 助手、版本、DAG、供应商和模型基座 | `/api/admin/agents/...` |
| `ADMIN_RAGFLOW_MANAGE` | 知识空间、文档入库、模型设置和检索测试 | `/api/admin/ragflow/...` |
| `ADMIN_CONTENT_SAFETY_MANAGE` | 注入检测、阻断标记和复核阈值 | `/api/admin/content-safety...` |
| `ADMIN_ORG_MANAGE` | 用户、学院、班级和岗位数据 | `/api/admin/users...`、`departments...`、`positions...` |
| `ADMIN_RBAC_MANAGE` | 管理员角色、权限及授权关系 | `/api/admin/rbac/...` |
| `ADMIN_FILE_MANAGE` | 文件对象、引用和清理治理 | `/api/admin/files/...` |
| `ADMIN_NOTIFICATION_CHANNEL_MANAGE` | 通知通道配置与测试 | `/api/admin/notification-channels...` |

管理端 Vue 路由和导航按同一权限码隐藏无权限入口；直接构造 URL 或请求仍会由后端过滤器复核。V54 已移除早期 `ADMIN_COURSE_MANAGE`，课程内容管理归教师端，不把课程经营权限混入后台管理员角色。

## 7. 登录、会话与账号安全

- 密码使用 BCrypt 校验，数据库不保存明文密码。
- 学生/教师和管理员分别使用专用 AuthenticationProvider。
- 登录成功前废弃旧 Session，再创建新 Session，降低 Session Fixation 风险。
- Session 默认存入 Redis，默认有效期为 7200 秒；退出登录立即使当前 Session 失效。
- 同一身份登录连续失败 5 次后，Redis 计数锁定 30 分钟；成功登录清除失败计数。
- 数据库账号状态支持 `ACTIVE/LOCKED/DISABLED` 等状态，锁定或禁用账号不能登录。
- 学生/教师邮箱二次验证受部署开关控制；启用时验证码 5 分钟有效、60 秒内禁止重复发送，验证成功后立即删除以防重放。
- 管理端和业务端前端都会在会话失效后引导重新登录，但不能替代后端 401/403 判定。

## 8. AI、画像与内容安全

### 8.1 最小化模型上下文

资源生成只向模型发送当前课程、章节、知识点、检索片段和任务所需画像维度，不发送完整人员档案。任务画像快照只包含版本、维度结论和置信信息。

### 8.2 输入脱敏

资源补充诉求和反馈在入库及模型处理前过滤：

- 邮箱地址；
- 手机号；
- 身份证号；
- 学号形式标识；
- API Key、Token、密码等疑似凭证。

### 8.3 内容安全与事实校验

- 可配置提示词注入检测和危险指令标记，命中后阻断任务或反馈提交。
- 复核置信度阈值决定低置信度内容是否进入教师复核。
- 生成资源保存知识文档、切片、摘录、页码和相关度，便于教师核对事实来源。
- 未通过事实校验的草稿不能直接发布；教师可修改、通过或拒绝。
- 内容安全配置使用 `version_no` 乐观锁，避免多人同时编辑互相覆盖。

## 9. 文件与资源访问安全

- 上传前校验场景策略、扩展名、MIME 类型和大小；上传票据包含用户范围和客户端幂等标识。
- 课程文件引用必须匹配 `owner_type=COURSE_RESOURCE` 和当前课程 ID。
- 教师读取或转换附件前校验教师角色、课程成员关系和附件归属。
- 学生只能读取已发布课程封面或已发布章节正文引用的课程附件。
- Office PDF 预览是独立附件引用，原文件下载和预览均经过后端权限入口。
- 客户端展示的附件 ID、课程 ID 和资源 ID 均视为不可信输入。

## 10. 模型凭证与部署配置

- 后台 AI 基座响应只返回凭证是否已配置，不把已保存 API Key 回传到浏览器。
- 更新模型或供应商时，不提交新凭证可保留原配置。
- AI 运行优先使用后台启用的默认文本模型；没有可用默认模型时回退部署环境 `AGENT_MODEL_*`。
- `.env` 或系统环境变量只保存在部署主机，不进入 Git、公开文档、日志、截图或比赛提交包。
- 数据库包含模型运行所需的凭证字段，因此正式库账号、备份文件和管理端入口必须限制访问并定期轮换凭证。

## 11. 审计与错误处理

- `sys_audit_log` 提供操作人、动作、目标、结果和时间等通用审计字段。
- 资源生成任务单独保存模型名、耗时、失败类型、失败原因及五角色步骤状态。
- 生成资源保存审核人、审核时间、审核意见和发布时间；学习记录保存首末查看时间。
- 接口对外返回可理解的业务错误，不返回 SQL、堆栈或模型凭证。
- 日志和测试报告不得记录密码、验证码、Session、Token、API Key 或完整个人隐私数据。

## 12. 当前边界与正式部署要求

当前后端关闭 CSRF 保护，适用于三端由同一受控站点提供、API 不向任意跨域来源开放的部署方式。正式对公网部署时必须：

1. 使用 HTTPS，并在反向代理或容器外服务层设置安全 Cookie 属性；
2. 保持前端与 API 同源，限制跨域和 WebSocket Origin；
3. 若必须开放跨站会话请求，在上线前补充 CSRF Token 方案并重新测试；
4. 限制 MySQL、Redis、文件目录和管理端端口的网络访问；
5. 为部署账号使用独立强密码，轮换比赛测试阶段使用过的凭证；
6. 定期备份并限制备份文件读取权限。

这些是非 Docker 部署的安全边界，不应通过把真实密钥写进代码或前端构建产物来简化配置。

## 13. 核验依据

- 全局认证与响应：`SecurityConfig`。
- 端身份隔离：`UserTypePathFilter`。
- 管理权限：`AdminPermissionFilter`、`AdminPermissionService`、后台路由与会话 Store。
- 教育角色与课程范围：`EducationRoleService`、`CourseResourceAccessService`、`CourseService`。
- 本人任务与资源范围：`LearningResourceService`、`LearningResourceRepository`。
- 登录与验证码：`LoginService`、`AuthLockService`、`EmailCodeService`、`AccountService`。
- 脱敏与内容安全：`LearningResourceService`、`LearningContentSafetyPolicyService`。
