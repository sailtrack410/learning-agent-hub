## 1. 系统交付范围

比赛系统目录包含后端、教育运营管理端、学生/教师端、脱敏环境变量样板和正式文档。`employee-web` 通过登录角色区分学生与教师；前端源码附带的 `shared-web` 只是必要编译依赖，不是第四个运行端。

| 目录或文件 | 内容 |
|---|---|
| `server/` | Spring Boot 生产源码和可执行 JAR |
| `admin-web/` | 教育运营管理端源码和生产静态文件 |
| `employee-web/` | 学生/教师端源码和生产静态文件 |
| `.env.example` | 非 Docker 部署的脱敏配置样板 |
| `docs/` | 本清单所列正式文档与教育核心 API/测试用例 |

## 3. 明确排除

本系统目录不包含：

- 真实 `.env`、API Key、Token、数据库密码或邮件授权码。
- Docker、Compose、容器镜像和容器专用配置。
- `node_modules`、普通 `target`、测试输出、日志、PID、缓存和数据库备份。
- 开发日志、代码审查记录、内部计划、原型、历史截图和旧交付压缩包。
- 移动端验收材料、演示视频、电子报名表和学生证。

演示视频、电子报名表和学生证由参赛团队按官网要求单独准备，不进入本次三端系统目录。
