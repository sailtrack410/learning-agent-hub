# 软件杯教育版提交文档清单

| 项目 | 内容 |
|---|---|
| 文档版本 | 1.0 |
| 更新日期 | 2026-07-19 |
| 适用范围 | 非 Docker 桌面 Web 三端比赛目录 |

## 1. 系统交付范围

比赛系统目录包含后端、教育运营管理端、学生/教师端、快速启动 README、脱敏环境变量样板和正式 Word/PPT 文档。`employee-web` 通过登录角色区分学生与教师；前端源码附带的 `shared-web` 只是必要编译依赖，不是第四个运行端。

| 目录或文件 | 内容 |
|---|---|
| `server/` | Spring Boot 生产源码和可执行 JAR |
| `admin-web/` | 教育运营管理端源码和生产静态文件 |
| `employee-web/` | 学生/教师端源码和生产静态文件 |
| `README.md` | 环境依赖、配置和三端快速启动说明 |
| `.env.example` | 非 Docker 部署的脱敏配置样板 |
| `docs/` | 产品功能、产品设计、测试、部署等正式 Word 文档与演示 PPT |

## 2. 正式文档

| 文档 | 主要内容 |
|---|---|
| 产品功能介绍 | 产品定位、三类角色、核心功能和演示流程 |
| 产品设计说明书 | 需求分析、总体方案、数据、权限、AI/RAG 与非功能设计 |
| 测试说明书 | 测试范围、用例、执行结果、真实模型和已知边界 |
| 部署说明书 | 环境依赖、配置、初始化、部署、备份和故障排查 |
| 演示 PPT | 作品展示与答辩演示 |
| 系统测试报告 | 442 项后端测试、双前端测试构建和真实模型全链路结果 |
| 开源软件与许可证清单 | 核心依赖、运行组件和许可证信息 |
| AI-Coding 工具使用说明 | AI 辅助开发范围、人工复核和安全边界 |

最终比赛目录放转换后的 Word、PPT 或按需导出的 PDF，以及上述三份技术附件。四份正式文档的 Markdown 源稿、配图源文件、`.obsidian`、`.claude` 和 `.DS_Store` 不进入提交包。

## 3. 明确排除

本系统目录不包含：

- 真实 `.env`、API Key、Token、数据库密码或邮件授权码。
- Docker、Compose、容器镜像和容器专用配置。
- `node_modules`、普通 `target`、测试输出、日志、PID、缓存和数据库备份。
- 开发日志、代码审查记录、内部计划、原型、历史截图和旧交付压缩包。
- 移动端验收材料、演示视频、电子报名表和学生证。

演示视频、电子报名表和学生证由参赛团队按官网要求单独准备，不进入本次三端系统目录。
