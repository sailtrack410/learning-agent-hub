# 企业协同人事平台 · 架构逻辑

---

## 一、系统总体架构拓扑

**四层架构：前端 → 网关 → 应用 → 数据 + 外部依赖**

- **前端层**
    - 员工 Web 端：Vue3 + Element Plus
    - 管理后台：Vue3
- **网关层**
    - Nginx：反向代理、静态资源
- **应用层**（Spring Boot 模块化单体）
    - HTTP API
    - WebSocket
    - 定时任务
    - Agent Worker
- **数据层**
    - MySQL：主业务库
    - PostgreSQL + pgvector：向量存储
    - Redis：缓存 / 会话
    - MinIO：文件存储
- **外部依赖**
    - 模型服务：LLM API
    - SMTP：邮件服务
    - 外部连接器

## 二、后端模块划分与依赖关系（14 模块）

### 基础层（被所有模块依赖）

- **module-common**：公共响应、异常、工具
- **module-spi**：跨模块服务契约，解耦用

### 认证与组织

- **module-auth**：登录、验证码、JWT 鉴权
    - 依赖 module-org（员工身份绑定）
- **module-org**：部门、岗位、员工、生命周期
- **module-admin**：后台 RBAC、菜单、系统配置

### 核心业务

- **module-workflow**：审批模板、申请、审批任务、抄送
    - 通过 SPI 被 Agent 调用
- **module-attendance**：考勤组、排班、打卡、结果计算
- **module-leave**：假期规则、账户、扣减流水

### 协同与智能

- **module-im**：会话、群组、WebSocket
    - 通过 SPI 被 Agent 调用
- **module-agent** ★：Agent 定义、版本、触发、任务、审计、权限裁剪
- **module-kb**：知识库、文档、切片、RAG 检索
- **module-doc**：文档空间、版本管理
- **module-connector**：外部连接器、凭证管理
- **module-notify**：邮件、App 推送、待办提醒

## 三、Agent 平台内部架构（核心创新）

### 生命周期

草稿 → 测试 → 发布 ⇄ 停用，发布后可回滚。

### 五大能力组件（发布后配置）

1. 模型选择 + 路由配置
2. Prompt 模板，版本管理
3. 工具绑定，白名单授权 + 参数校验
4. 知识库 RAG 绑定
5. 工作流编排定义

### 四种触发方式

- 会话中 @Agent 触发
- 审批流程节点触发（预审）
- 定时任务触发
- 事件驱动触发（入职 / 离职等）

### 三线权限裁剪（核心安全机制）

> 最终执行权限 = Agent自身权限 ∩ 当前用户授权范围 ∩ 业务/知识范围

三条线取交集，确保 Agent 不会越权执行。

## 四、核心业务流程

### 考勤闭环：打卡 → 考勤计算 → 异常 → 补卡

1. **员工打卡**
    - 合规 → 正常打卡记录
    - 异常 → 异常记录
2. **考勤结果计算**：迟到 / 早退 / 旷工判定
3. **员工查看考勤结果**
    - 无异议 → 确认归档 ✅
    - 有异议 → 发起补卡申请
4. **补卡申请处理**
    - Agent 预审（硬规则校验）
        - 违规 → 自动驳回 ❌
        - 合规 → 直属上级审批
    - 审批结果
        - 通过 → 考勤结果修正 → 归档
        - 驳回 → 通知员工

## 五、核心数据域关系总览

### 组织域（核心枢纽）

- **org_department**（部门）
    - 1:N → org_user（员工）
    - 1:N → 部门领导 / 上级
    - 1:N → im_group（组织群）
- **org_user**（员工）
    - 1:1 → auth_account（登录账号）
    - 1:N → wf_application（审批申请）
    - 1:N → att_clock_record（打卡记录）
    - 1:N → lv_leave_account（假期账户）
    - 1:N → im_message（聊天消息）
    - N:M → im_group_member（群成员）

### 审批域

- **wf_application**（审批申请）
    - 1:N → wf_approval_task（审批任务）
    - 1:N → agt_audit_log（Agent 预审记录）

### Agent 域

- **agt_agent**（Agent 定义）
    - 1:N → agt_agent_version（版本记录）
    - 1:N → agt_tool_binding（工具绑定）
    - 1:N → kb_knowledge_binding（知识库绑定）
    - 1:N → agt_execution_log（执行日志）

### 知识库域

- **kb_knowledge**（知识库）
    - 1:N → kb_document（知识文档）
    - 1:N → kb_chunk（知识切片）
        - 1:1 → pg_embedding（向量存储，PostgreSQL pgvector）

### 考勤域

- **att_schedule_group**（考勤组）
    - 1:N → att_schedule_record（排班记录）
    - 1:N → org_user（考勤归属）
