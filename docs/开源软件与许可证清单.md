# 开源软件与许可证清单

| 项目 | 内容 |
|---|---|
| 文档版本 | 1.0 |
| 更新日期 | 2026-07-19 |
| 适用范围 | 非 Docker 三端源码与构建产物 |

本文档列出 Learning Agent Hub 直接使用的核心框架、构建工具和外部运行组件。比赛目录只交付后端 JAR 与两套前端静态文件，不交付第三方数据库、缓存、Web 服务器或容器镜像。间接依赖的完整版本以 Maven、npm 锁文件和最终构建产物内许可证元数据为准。
