## 3. 页面流程

### 3.1 教育运营管理员

- 运营概览可加载 AI 任务、课程知识库和文件空间指标。
- AI 基座显示供应商、模型列表、默认模型与连接测试入口。
- 默认模型页明确说明语言模型会实际用于画像分析、路径规划、内容生成、练习生成和事实校验，未设置时回退部署配置。
- 知识库、内容安全、用户与班级、角色权限、权限点、文件空间、消息投递和审计日志入口可达。
- 内容安全页面显示注入拦截、复核阈值、危险标记、版本与审计说明。

### 3.2 教师

- 课程列表展示网格/列表切换、新建课程和《Java Web 应用开发》课程卡片。
- 课程工作区覆盖基础信息、章节文章、课程资料库、学情分析和生成资源。
- 资料库显示解析与向量化状态；刷新页面后重新读取持久化任务状态。
- DOCX 资料上传后约 3 秒完成异步 PDF 转换，页面内可直接预览，底部可下载原文件。
- 学情分析展示班级、风险学生、课程完成率、平均掌握度和薄弱知识点。
- 生成资源页稳定展示 2 条生成任务、10 条已发布资源，以及五角色执行轨迹、资源校验结论、审核、发布、撤回和推送入口。
- 课程邀请链接流程由独立集成测试验证：协作者可以编辑课程，但不能删除课程，非课程教师不可查看或修改。
- 桌面侧栏和移动端底部均提供退出入口，退出后返回登录页并清除业务会话。

### 3.3 学生

- 学习首页显示今日任务、学习进度、平均掌握度、待完成练习与推荐资源。
- 学习画像显示 8/8 维度、画像 V13、结论、置信度、依据与更新时间。
- 学习路径显示路径 V3、画像版本、14 个节点、推荐理由与完成状态。
- 个性化资源显示 5 类已发布资源及五智能体阶段耗时；五角色节点可查看输入摘要、模型、耗时和结构化输出摘要，生成中正文通过 SSE 增量展示并可在刷新后恢复。
- 学生对代码实操反馈“太难”后，页面显示反馈写入画像 V13；资源偏好结论和证据同步记录资源名称、反馈类型及补充说明。
- 课程测验显示 6 题、100 分、题型、知识点、答题进度和提交流程。
- 提交测验获得 50/100 后，画像由 V11 更新至 V12，路径由 V2 重排至 V3；错误知识点集中在 Servlet 生命周期、Spring Boot 自动配置和权限控制，教师学情页同步显示新的画像与风险状态。

## 4. 真实智能体验收

- 任务 ID：`1870695121604837376`，模型均为 `deepseek-ai/DeepSeek-V3.2`。
- 五阶段总耗时 259.563 秒：画像分析 21.652 秒、路径规划 16.103 秒、内容生成 103.186 秒、练习生成 87.656 秒、事实校验 30.482 秒。
- 生成讲解、练习、案例、思维导图和复习清单 5 类资源；每类均通过事实校验，置信度 95%，并关联 2 条课程知识库引用。
- 教师审核发布后，学生端可以查看全部 5 类资源、推荐理由、校验结论和引用。

## 5. 响应式与控制台

- 管理端移动端使用抽屉导航，文档宽度与视口均为 390px。
- 学生个性化资源移动页文档宽度与视口均为 390px；五智能体轨迹在移动端改为单列，不产生页面级或组件级横向滚动。
- 验收过程中浏览器控制台未发现未处理异常、Vue 警告或接口噪声。
