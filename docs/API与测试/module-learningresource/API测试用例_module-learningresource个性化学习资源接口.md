| `LEARNING-RESOURCE-045` | 教师端打开推送弹窗 | 可在弹窗内选择班级或搜索学生，不滚动定位页面 |
| `LEARNING-RESOURCE-046` | 学生提交有帮助、太难、太简单或不相关反馈 | 保存本人唯一反馈，更新资源偏好画像并写版本与证据 |
| `LEARNING-RESOURCE-047` | 学生重复提交完全相同反馈 | 返回原反馈，不重复增加画像版本 |
| `LEARNING-RESOURCE-048` | 学生修改反馈 | 更新反馈并生成新的可追溯画像版本 |
| `LEARNING-RESOURCE-049` | 反馈说明包含手机号、凭证或危险指令 | 隐私字段脱敏；危险指令返回 `400` 且不更新画像 |
| `LEARNING-RESOURCE-050` | 在管理端 AI 基座配置启用默认 `TEXT` 模型并继承部署环境连接参数 | 资源生成优先固定使用该模型；任务只记录模型名称，不泄露端点或密钥；未配置时回退部署环境模型 |
| `LEARNING-RESOURCE-051` | OpenAI 兼容模型返回 SSE 分片 | 客户端按顺序累计正文，步骤保存受限长度实时内容，刷新后可恢复 |
| `LEARNING-RESOURCE-052` | 默认文本模型启用结构化输出 | 五角色请求携带 `response_format=json_object`，并按单一 JSON 对象验收 |
| `LEARNING-RESOURCE-053` | 流式请求返回 `408`、`429` 或 `5xx` | 清除已有不完整流，在角色共享总超时内最多同步降级一次，不拼接新旧正文 |
| `LEARNING-RESOURCE-054` | 流式请求发生网络异常或 Spring AI 0.8.1 兼容 SSE 空指针异常 | 在角色共享总超时内最多同步降级一次；同步成功时按正常结构继续任务 |
| `LEARNING-RESOURCE-055` | 流式任务达到角色总超时 | 取消上游调用并返回 `TIMEOUT`，不在超时后启动同步降级 |
| `LEARNING-RESOURCE-056` | 结构化流正常结束但为空、不是 JSON 对象或对象主体有尾随值 | 同步降级一次；同步结果仍非法时返回 `INVALID_RESPONSE` |
| `LEARNING-RESOURCE-057` | 流式请求返回 `401` 或 `403` | 不执行同步降级，保留精确鉴权失败分类 |
| `LEARNING-RESOURCE-058` | 同步降级再次遇到限流、服务端错误、超时或非法响应 | 不再进行第二次高层降级，按 `RATE_LIMITED`、`PROVIDER_ERROR`、`TIMEOUT` 或 `INVALID_RESPONSE` 结束 |
| `LEARNING-RESOURCE-059` | 校验五角色输出与超时预算 | 依次固定为 `1024/60s`、`1536/60s`、`3072/180s`、`3072/180s`、`2048/120s`，同步降级不重置计时 |
| `LEARNING-RESOURCE-060` | 未配置管理端默认模型，资源生成直接使用部署环境模型 | 不强制发送 `response_format`，但仍按单一 JSON 对象严格校验，非法流可在共享总超时内同步降级一次 |

后端接口、幂等、权限与发布流转覆盖位于 `ModuleLearningResourceApiIntegrationTest`；管理员内容安全权限、并发、审计覆盖位于 `ModuleContentSafetyAdminApiIntegrationTest`；角色输出上限、超时和可配置复核阈值覆盖位于 `LearningResourceGenerationServiceTest`；结构化 JSON 模式、共享总超时、流式错误分类和单次同步降级覆盖位于 `AgentModelClientSpringAiTest`；首个管理员初始化覆盖位于 `EducationAdminBootstrapIntegrationTest`。学生端和管理端 API、路由及页面契约由前端自动化测试覆盖。真实模型验收使用脱敏的《Java Web 应用开发》演示学生数据。
