# module-learningresource 个性化学习资源测试用例

| 编号 | 场景 | 预期结果 |
|---|---|---|
| `LEARNING-RESOURCE-001` | 未登录创建生成任务 | 返回 `401` |
| `LEARNING-RESOURCE-002` | 教师调用学生任务创建接口 | 返回 `403` |
| `LEARNING-RESOURCE-003` | 缺少课程、知识点或幂等键 | 返回 `400` 和可理解校验消息 |
| `LEARNING-RESOURCE-004` | 学生对已发布课程创建任务 | 保存当前画像版本和脱敏画像快照，返回 `PENDING` |
| `LEARNING-RESOURCE-005` | 同一学生使用同一幂等键重复提交相同指纹 | 返回原任务，不重复生成 |
| `LEARNING-RESOURCE-006` | 同一幂等键改变课程或知识点 | 返回 `409` |
| `LEARNING-RESOURCE-007` | 补充诉求包含手机号等个人信息 | 入库和发给模型前完成脱敏 |
| `LEARNING-RESOURCE-008` | 补充诉求包含忽略规则、删库或越权调用工具指令 | 返回 `400`，不创建任务 |
| `LEARNING-RESOURCE-009` | 课程知识库未建立或无可引用切片 | 任务失败，失败类型为知识未就绪 |
| `LEARNING-RESOURCE-010` | 真实模型执行五角色 | 按固定顺序记录 5 个步骤、模型、耗时和输出摘要 |
| `LEARNING-RESOURCE-011` | 五角色全部成功 | 生成 5 类资源，每类每任务只有一条 |
| `LEARNING-RESOURCE-012` | 模型返回截断或非法 JSON | 任务失败，保留已完成步骤和错误原因 |
| `LEARNING-RESOURCE-013` | 模型调用超时 | 任务失败，失败类型为 `TIMEOUT` |
| `LEARNING-RESOURCE-014` | 本人重试失败任务 | `attemptNo` 递增、进度清零，历史步骤保留 |
| `LEARNING-RESOURCE-015` | 重试非失败任务 | 返回 `409` |
| `LEARNING-RESOURCE-016` | 其他学生查询或重试任务 | 返回 `404`，不泄露任务是否存在 |
| `LEARNING-RESOURCE-017` | 事实校验返回通过、需复核或拒绝 | 保存逐资源结论、原因和置信度 |
| `LEARNING-RESOURCE-018` | 事实校验置信度低于 75% 但结论为通过 | 系统将结论降级为需复核 |
| `LEARNING-RESOURCE-019` | 查询资源详情 | 返回课程、章节、知识点、正文、校验和 RAG 引用 |
| `LEARNING-RESOURCE-020` | 学生查询待审核或已撤回资源 | 列表不返回，详情返回 `404` |
| `LEARNING-RESOURCE-021` | 课程所有者或协作教师查询任务与资源 | 可按课程、知识点、类型和状态筛选 |
| `LEARNING-RESOURCE-022` | 非参与教师访问资源 | 返回 `404` |
| `LEARNING-RESOURCE-023` | 教师修改待审核资源 | 更新标题、摘要和正文，清除旧审核和发布时间 |
| `LEARNING-RESOURCE-024` | 教师拒绝资源但未填原因 | 返回 `400` |
| `LEARNING-RESOURCE-025` | 教师通过并发布资源 | 资源变为 `PUBLISHED`，仅所属学生可见 |
| `LEARNING-RESOURCE-026` | 教师撤回已发布资源 | 资源变为 `WITHDRAWN`，学生立即不可见 |
| `LEARNING-RESOURCE-027` | 修改已发布资源 | 返回 `409`，必须先撤回 |
| `LEARNING-RESOURCE-028` | SSE 连接成功 | 返回当前任务并持续推送阶段、进度和当前角色正文增量，终态后关闭 |
| `LEARNING-RESOURCE-029` | SSE 异常中断 | 学生端降级为定时查询，页面刷新后可恢复状态 |
| `LEARNING-RESOURCE-030` | 学生端打开五类已发布资源 | Markdown、表格、代码、思维导图、校验结论和引用正常渲染 |
| `LEARNING-RESOURCE-031` | 1280px 桌面端和 390px 移动端实测 | 无横向溢出、遮挡和控制台异常 |
| `LEARNING-RESOURCE-032` | 未登录或无内容安全权限查询策略 | 分别返回 `401`、`403` |
| `LEARNING-RESOURCE-033` | 超级管理员查询内容安全策略 | 返回开关、阈值、危险标记、版本和更新时间 |
| `LEARNING-RESOURCE-034` | 管理员更新内容安全策略 | 规则即时生效、版本递增并写审计日志 |
| `LEARNING-RESOURCE-035` | 使用旧版本并发更新策略 | 返回 `409`，不覆盖新策略 |
| `LEARNING-RESOURCE-036` | 启用注入拦截但清空危险标记 | 返回 `400` |
| `LEARNING-RESOURCE-037` | 配置自定义危险标记后创建任务 | 命中自定义标记时返回 `400`，不创建任务 |
| `LEARNING-RESOURCE-038` | 事实校验低于管理员配置阈值 | 通过结论降级为 `NEEDS_REVIEW` |
| `LEARNING-RESOURCE-039` | 教师向班级推送本人课程的已发布资源 | 创建 `ACTIVE` 推送，班级学生可在列表和详情中访问 |
| `LEARNING-RESOURCE-040` | 教师重复向同一目标推送同一资源 | 返回原推送并恢复为 `ACTIVE`，不创建重复记录 |
| `LEARNING-RESOURCE-041` | 学生或非课程教师调用推送接口 | 分别返回 `403` 和 `404`，不新增推送关系 |
| `LEARNING-RESOURCE-042` | 教师推送草稿、撤回或拒绝资源 | 返回状态冲突，学生不可访问 |
| `LEARNING-RESOURCE-043` | 学生打开本人可访问的资源 | 首次和最近查看时间更新，查看次数累加 |
| `LEARNING-RESOURCE-044` | 学生记录无权访问资源的查看行为 | 返回 `404`，不写使用记录 |
| `LEARNING-RESOURCE-045` | 教师端打开推送弹窗 | 可在弹窗内选择班级或搜索学生，不滚动定位页面 |
| `LEARNING-RESOURCE-046` | 学生提交有帮助、太难、太简单或不相关反馈 | 保存本人唯一反馈，更新资源偏好画像并写版本与证据 |
| `LEARNING-RESOURCE-047` | 学生重复提交完全相同反馈 | 返回原反馈，不重复增加画像版本 |
| `LEARNING-RESOURCE-048` | 学生修改反馈 | 更新反馈并生成新的可追溯画像版本 |
| `LEARNING-RESOURCE-049` | 反馈说明包含手机号、凭证或危险指令 | 隐私字段脱敏；危险指令返回 `400` 且不更新画像 |
| `LEARNING-RESOURCE-050` | 配置管理端启用默认文本模型 | 资源生成优先固定使用该模型；未配置时回退部署环境模型 |
| `LEARNING-RESOURCE-051` | OpenAI 兼容模型返回 SSE 分片 | 客户端按顺序累计正文，步骤保存受限长度实时内容，刷新后可恢复 |

后端接口、幂等、权限与发布流转覆盖位于 `ModuleLearningResourceApiIntegrationTest`；管理员内容安全权限、并发、审计覆盖位于 `ModuleContentSafetyAdminApiIntegrationTest`；角色输出上限、超时和可配置复核阈值覆盖位于 `LearningResourceGenerationServiceTest`；首个管理员初始化覆盖位于 `EducationAdminBootstrapIntegrationTest`。学生端和管理端 API、路由及页面契约由前端自动化测试覆盖。真实模型验收使用脱敏的《Java Web 应用开发》演示学生数据。

## 真实模型与 RAG 验收记录

- 验收日期：2026-07-13
- 课程：《Java Web 应用开发》
- 知识点：HTTP 请求与响应
- 画像版本：V11
- 入库文档：`01-servlet-http.md`，解析并向量化为 2 个切片
- 生成模型：`deepseek-ai/DeepSeek-V3.2`
- 第一次：内容生成阶段因 512 tokens 上限截断 JSON，任务正确失败并记录原因
- 第二次：内容生成成功，练习生成在 90 秒超时，任务正确失败并保留步骤
- 第三次：五角色全部成功，总耗时 373.738 秒
  - 画像分析：10.896 秒
  - 路径规划：14.307 秒
  - 内容生成：133.603 秒
  - 练习生成：165.003 秒
  - 事实校验：49.415 秒
- 结果：生成并发布 5 类资源，事实校验置信度均为 95%
- 引用：每条资源关联同一文档的 2 个检索切片，相关度分别为 0.809924 和 0.539704
- 人工核验：讲解文档的 HTTP 方法、状态码、Servlet 生命周期和线程安全结论可由引用切片支持；思维导图节点与同一课程资料一致
- 浏览器：学生端和教师端桌面视图、390px 学生端移动视图均无横向溢出，控制台无警告或未处理异常
