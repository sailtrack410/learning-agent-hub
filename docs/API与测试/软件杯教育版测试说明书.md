# 软件杯教育版测试说明书

## 1. 测试目标

验证课程、画像、评估、学习路径、个性化资源、RAG、文件预览、教师协作、管理员治理和三端交互可以组成完整且安全的演示闭环。

## 2. 自动化测试范围

- 后端单元测试：画像更新、路径节点推进与测验重排、资源生成状态、课程资源权限、Office 转换和数据集完整性。
- 后端集成测试：课程、画像、评估、路径、资源、学习首页、管理员内容安全、认证和横向越权。
- 管理端测试：路由、权限、课程运营相关治理、AI 任务、知识库、文件、内容安全和交互约束。
- 学生/教师端测试：API 契约、角色路由、课程管理、附件预览、资源审核、画像、路径、首页和个人中心。

## 3. 必测边界

| 类别 | 场景 |
|---|---|
| 认证 | 未登录访问、错误账号、会话失效、管理员与业务用户会话隔离 |
| 角色 | 学生访问教师接口、教师访问学生画像、业务用户访问管理员接口 |
| 数据权限 | 非课程教师访问课程、学生读取草稿课程或其他学生资源 |
| 幂等 | 重复提交测验、资源生成、课程资料、附件预览和资源推送 |
| 状态 | 草稿/发布、任务成功/失败/重试、路径顺序、审核/发布/撤回 |
| 依赖失败 | 模型失败、向量失败、Office 失败、对象存储失败、超时 |
| 并发 | 学习节点重复完成、路径活动版本、入库活动任务、内容安全版本冲突 |
| UI | 加载、空状态、错误、无权限、长文本、桌面和移动端溢出 |

## 4. 完整验证命令

```bash
cd server && mvn test
cd admin-web && npm run test
cd admin-web && npm run build
cd employee-web && npm run test
cd employee-web && npm run build
scripts/run-browser-acceptance.sh
```

交付打包额外执行：

```bash
cd server && mvn package
```

## 5. 浏览器端到端流程

1. 管理员登录，检查模型、智能体、知识库和内容安全策略。
2. 教师登录，创建课程、维护章节和文章，上传课程资料并等待入库完成。
3. 课程所有者生成邀请，第二名教师接受并验证协作编辑与禁止删除。
4. 学生登录，完成画像对话并生成学习路径。
5. 学生创建个性化资源任务，观察五角色进度并刷新恢复。
6. 教师审核并发布资源，选择学生或班级推送。
7. 学生查看资源、引用和推荐理由，完成测验。
8. 验证画像版本、掌握度和学习路径发生可追溯变化。
9. 教师查看学情分析中的风险、薄弱知识点和资源使用变化。

## 6. 数据集测试

`deliverables/course-data/java-web` 包含三类学生画像、常见错误、24 条事实校验和 12 条安全样本。`EducationCourseDatasetTest` 在后端测试中自动校验数量、唯一性、画像维度和事实来源。
