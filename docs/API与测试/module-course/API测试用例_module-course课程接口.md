# module-course 课程接口测试用例

| 编号 | 场景 | 预期 |
|---|---|---|
| `COURSE-001` | 教师创建课程 | 创建者成为 `OWNER`，列表可见 |
| `COURSE-002` | 未参与教师查询或修改课程 | 列表不返回该课程，详情与修改拒绝 |
| `COURSE-003` | 所有者生成邀请，另一教师接受 | 接受者成为 `COLLABORATOR`，可编辑课程和章节 |
| `COURSE-004` | 协作者删除课程或生成邀请 | 返回 `403`，课程不变 |
| `COURSE-005` | 接受过期邀请 | 返回 `410`，不新增成员关系 |
| `COURSE-006` | 第三名教师使用已接受邀请 | 返回 `409`，不新增成员关系 |
| `COURSE-007` | 学生访问草稿课程或草稿章节资源 | 拒绝访问 |
| `COURSE-008` | 教师访问非本人管理课程资源 | 拒绝访问 |
| `COURSE-009` | 教师保存含图片、视频、附件的文章 | 资源属于当前课程时保存成功，跨课程引用返回 `400` |
| `COURSE-010` | 学生打开已发布文章内资源 | 仅已发布课程和章节中的 `attachmentRefId` 可读取 |
| `COURSE-011` | 教师上传 Word 或 PowerPoint 并请求预览 | 接口快速返回 `CONVERTING`，后台生成 PDF 副本，最终状态为 `READY`，正文嵌入预览且底部可下载原文件 |
| `COURSE-012` | 重复请求同一附件预览 | 复用已有预览，不重复创建文件对象 |
| `COURSE-013` | 学生访问未发布附件的预览 | 返回 `403`，不暴露预览副本 |
| `COURSE-014` | 课程教师查询学情概览 | 返回课程、班级、学生画像摘要、进度、风险原因、掌握度、薄弱知识点和资源使用统计 |
| `COURSE-015` | 非课程教师查询学情概览 | 返回 `404`，不泄露课程学习数据 |
| `COURSE-016` | 学情概览存在未分班学生或暂无测验数据 | 学生仍计入课程总览，班级 ID 和掌握度允许为空，页面显示明确空状态 |
| `COURSE-017` | 学生查询学习首页 | 返回今日任务、总体进度、平均掌握度、待完成练习、推荐资源和逐课程当前节点 |
| `COURSE-018` | 未登录或教师查询学生学习首页 | 未登录返回 `401`，教师返回 `403`，不泄露学生学习数据 |
| `COURSE-019` | 学生尚未生成学习路径或没有测验、推荐 | 接口返回零值和空列表，不创建路径或写入学习状态，页面显示明确空状态 |
| `COURSE-020` | Office 转换过程中刷新文章编辑页 | 页面根据 `attachmentRefId` 恢复轮询，完成后重新显示 PDF 预览和原文件下载入口 |
| `COURSE-021` | 查询不存在、超限或不支持类型的预览 | 不创建 PDF 文件对象，返回明确错误；原文件和文章内容不变 |
| `COURSE-022` | 课程资料异步入库 | 首次立即返回 `PENDING`，轮询可观察阶段和进度递增，成功为 `SUCCESS/100/COMPLETED`；失败可重试且不重复创建课程资料关系 |
| `COURSE-023` | 学生首次及重复加入已发布课程 | 首次建立课程学生关系并返回 `enrolled=true`，重复调用不新增记录 |
| `COURSE-024` | 教师查询课程学情和搜索学生 | 只返回已加入当前课程的学生，不返回平台其他学生 |
| `COURSE-025` | 教师对课程学生发起私聊 | 同一教师和学生重复发起返回同一私聊；未加入课程学生返回 `404` |
| `COURSE-026` | 教师进入课程班级群 | 同一课程班级重复进入返回同一群，成员为课程教师和该班已加入学生 |
| `COURSE-027` | 学生或非课程教师调用课程沟通接口 | 返回 `403/404`，不创建会话和成员关系 |
