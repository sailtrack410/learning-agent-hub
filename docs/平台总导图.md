# 企业协同人事平台总导图（第一版）

## 一、平台定位
- 员工协同
- 团队管理
- 人事流程
- 系统治理
- 多端统一业务平台

## 二、角色体系
### 1. 业务用户体系
#### 员工
- 完成个人日常协同事务

#### 领导
- 继承员工能力
- 增加团队管理能力

### 2. 系统治理体系
#### 管理员
- 完成系统级治理与配置

## 三、入口与端架构
### 1. C端 / 职工端（Web）
- 使用者：员工、领导
- 面向：日常业务协同
- 特点：信息更完整，适合中低频复杂操作

### 2. 小程序端
- 使用者：员工、领导
- 面向：高频移动操作
- 特点：与 C 端共享同一业务能力，差异只在 UI 与交互

### 3. B端 / 管理后台
- 使用者：管理员
- 面向：系统治理
- 特点：配置化、规则化、治理化

### 4. 后端服务
- 统一权限体系
- 统一流程体系
- 统一业务规则
- 统一数据模型

## 四、核心设计原则
- 角色决定能力，组织决定范围
- 组织模型不直接等于流程模型
- 审批人不是固定个人，而是动态解析结果
- 领导是业务用户增强身份，不是后台用户
- 管理员独立于业务用户体系
- C端与小程序共享同一业务域
- 组织架构是可配置的基础模型
- 员工生命周期以状态、事件与生效时间驱动业务联动

## 五、组织模型
### 1. 组织单元
- 部门
- 上级部门
- 子部门
- 组织层级

### 2. 用户归属
- 一个用户一个主部门
- 管理员不进入业务组织树

### 3. 部门负责人
- 正职负责人
- 组织意义上的第一负责人

### 4. 部门领导成员
- 可存在多个
- 包含副职领导
- 用于审批、排班、管理范围参考

### 5. 汇报关系
- 每个业务用户一个直属上级
- 直属上级必须具备领导身份
- 汇报关系第一版与组织树保持一致

### 6. 组织架构可配置边界
#### 第一版必须支持
- 树状部门
- 用户主部门归属
- 部门负责人配置
- 直属上级配置
- 多领导成员配置

#### 第一版暂不支持
- 多主部门
- 多直属上级
- 虚线汇报
- 复杂矩阵组织

## 六、权限模型
### 1. 数据可见范围
- 员工：仅自己
- 领导：自己部门及子部门
- 管理员：全局

### 2. 操作权限
- 员工：发起、查看、修改个人信息
- 领导：员工能力 + 审批 + 排班 + 团队查看
- 管理员：配置、治理、全局查看

### 3. 审批资格
- 不固定赋给某个人
- 由流程规则动态计算
- 结合组织关系、角色与审批策略生成

## 七、审批与流程模型
### 1. 流程类型
- 入职
- 转正
- 调岗
- 调部门
- 请假
- 调休
- 加班
- 离职
- 补卡

### 2. 流程基础结构
- 发起
- 审批节点
- 审批结果
- 流程结束

### 3. 审批人确定原则
- 第一层：直属上级
- 第二层：部门领导层
- 第三层：上级部门逐级升级

### 4. 部门审批策略
- 任意一人通过
- 全部会签
- 主管优先，副主管兜底

### 5. 流程状态
- 草稿
- 待审批
- 审批中
- 已通过
- 已驳回
- 已撤回

### 6. 流程原则
- 不写死审批人
- 节点绑定规则，不绑定个人
- 审批链由规则动态生成

## 八、业务模块
### 1. 考勤管理
#### 能力
- 签到/签退
- 打卡校验
- 补卡申请
- 考勤记录
- 考勤状态计算

#### 端承载
- C端：完整业务操作
- 小程序：高频主入口
- 后台：规则配置与治理

### 2. 申请与审批
#### 能力
- 请假申请
- 调休申请
- 加班申请
- 离职申请
- 审批流处理
- 审批记录查询

#### 端承载
- C端：员工发起、领导审批
- 小程序：移动发起与审批
- 后台：模板与审批规则配置

### 3. 排班管理
#### 能力
- 班次查看
- 员工排班
- 默认班次
- 特殊班次调整
- 排班结果查询

#### 端承载
- C端：员工看个人排班、领导管团队排班
- 小程序：轻量查看与操作
- 后台：班次模板与基础规则

### 4. 组织与人员
#### 能力
- 部门管理
- 角色/岗位管理
- 员工档案
- 上下级关系
- 权限归属

#### 端承载
- C端：个人信息、团队成员简版查看
- 小程序：个人与轻量团队视图
- 后台：完整维护

### 5. 员工全生命周期管理
#### 能力
- 入职办理
- 转正办理
- 调岗申请
- 调部门申请
- 上级变更
- 考勤组变更
- 离职办理
- 员工状态管理
- 生命周期时间线
- 异动记录查询

#### 端承载
- C端：个人发起、进度查询、历史查看
- 小程序：移动发起、移动查看进度
- 后台：入转调离办理、异动台账维护

### 6. 消息通知
- 审批提醒
- 异常打卡提醒
- 请假结果通知
- 系统公告

### 7. 统计报表
- 个人考勤统计
- 团队考勤统计
- 请假统计
- 排班统计
- 异常分析

### 8. 系统配置
- 打卡规则
- 请假类型
- 班次模板
- 审批流模板
- 参数配置
- 审计日志
