# Learning Agent Hub 部署与初始化说明书

| 项目 | 内容 |
|---|---|
| 文档版本 | 1.0 |
| 更新日期 | 2026-07-19 |
| 适用范围 | 软件杯教育版桌面 Web 三端 |
| 部署方式 | 后端可执行 JAR + 管理端静态文件 + 学生/教师端静态文件 |

## 1. 交付结构

正式比赛目录只保留以下内容：

```text
competition-submission/
├── server/
│   ├── learning-agent-hub-server.jar
│   └── source/
├── admin-web/
│   ├── dist/
│   └── source/
├── employee-web/
│   ├── dist/
│   └── source/
├── .env.example
└── docs/
```

`employee-web` 根据登录角色展示学生端或教师端。两个前端源码中的 `shared-web` 是必要编译依赖，不是第四个运行端。

本方案不使用 Docker。比赛目录不包含 Docker 配置、依赖缓存、运行日志、数据库备份、截图、视频或真实凭证。

## 2. 环境要求

| 组件 | 要求 | 用途 |
|---|---|---|
| JDK | 17 | 运行 Spring Boot JAR |
| MySQL | 8.0 | 业务数据与 Flyway 迁移 |
| Redis | 6 或 7 | 登录会话与短期状态 |
| Nginx | 稳定版本，或等价静态服务器 | 托管两个 `dist` 并同源转发 API |
| LibreOffice | 按需安装 | Word、PowerPoint 转 PDF 预览 |
| OpenAI 兼容模型服务 | 按需启用 | 画像、路径和五智能体资源生成 |
| PostgreSQL + pgvector | 按需启用 | 外部向量检索 |
| SMTP | 按需启用 | 邮箱验证码和通知 |

默认文件存储为本机文件系统，不要求安装 MinIO。正式目录必须具有独立、可备份的文件数据路径。

Flyway 9.22.3 已在 MySQL 8.0 范围完成验证；MySQL 8.4 会出现超出该 Flyway 版本已验证范围的提示，因此比赛环境固定使用 MySQL 8.0。

## 3. 配置 `.env`

在比赛目录根部执行：

```bash
cp .env.example .env
```

至少修改以下变量：

```text
DB_HOST
DB_PORT
DB_NAME
DB_USER
DB_PASSWORD
REDIS_HOST
REDIS_PORT
REDIS_PASSWORD
WORKFORCE_FILE_LOCAL_ROOT
IM_WEBSOCKET_ALLOWED_ORIGIN_PATTERNS
```

`.env` 是部署机器私有配置，不得提交 Git、上传比赛官网或发送给无关人员。`.env.example` 只保留空值和占位值。

两个前端生产包默认通过同源 `/api` 和 `/ws` 访问后端，因此运行时不读取根目录 `.env`。若必须跨域直连，需在构建前设置 `VITE_API_BASE_URL`，并同步配置后端跨域和 Cookie 策略；比赛环境推荐使用同源反向代理。

## 4. 初始化 MySQL 与 Redis

先创建独立数据库和最小权限账号，数据库字符集使用 `utf8mb4`。禁止覆盖、清空或重建已有数据库。

后端首次启动时，Flyway 自动从首个迁移执行到当前 V72。正式环境保持：

```text
FLOWABLE_DB_SCHEMA_UPDATE=false
```

Flowable 表同样由 Flyway 管理，不允许用 Flowable 自动改库掩盖迁移缺失。

Redis 启动后确认 `.env` 中的主机、端口和密码可用。生产或比赛公开网络中不得暴露无认证的 Redis 端口。

## 5. 首次管理员

全新数据库第一次启动前，在私有 `.env` 中设置：

```text
EDUCATION_ADMIN_BOOTSTRAP_ENABLED=true
EDUCATION_ADMIN_LOGIN=<首次管理员登录名>
EDUCATION_ADMIN_PASSWORD=<8到64位强密码>
EDUCATION_ADMIN_DISPLAY_NAME=教育运营管理员
```

初始化只在 `admin_user` 为空时创建首个账号并授予 `SUPER_ADMIN`。确认管理员能够登录后，将 `EDUCATION_ADMIN_BOOTSTRAP_ENABLED` 改回 `false`，再重启后端。初始化逻辑不会重置现有密码、恢复停用账号或把普通管理员提升为超级管理员。

## 6. 启动后端

比赛目录根部保存 `.env`，然后从 `server` 目录启动：

```bash
cd server
java -jar learning-agent-hub-server.jar
```

JAR 会读取当前目录的 `.env` 或父目录的 `../.env`。启动成功后检查：

```text
http://127.0.0.1:8080/actuator/health
```

预期状态为 `UP`。启动日志不得输出数据库密码、Token、模型密钥或完整个人信息。

## 7. 托管两个前端

以下示例让管理端运行在 `5173`，学生/教师端运行在 `5174`，两端都把 API 转发到本机 `8080`。部署时把 `/absolute/path/competition-submission` 换成真实绝对路径。

```nginx
server {
    listen 5173;
    server_name 127.0.0.1;
    root /absolute/path/competition-submission/admin-web/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

server {
    listen 5174;
    server_name 127.0.0.1;
    root /absolute/path/competition-submission/employee-web/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /ws/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

访问地址：

- 教育运营管理端：`http://127.0.0.1:5173/`
- 学生/教师端：`http://127.0.0.1:5174/`
- 后端健康检查：`http://127.0.0.1:8080/actuator/health`

## 8. 配置 AI 基座

有两条生效路径：

1. 管理端“AI 基座”中启用供应商并配置一个启用的默认 `TEXT` 模型。
2. 管理端没有可用默认文本模型时，回退到私有 `.env` 中的 `AGENT_MODEL_*` 配置。

环境变量样板：

```text
AGENT_MODEL_ENABLED=true
AGENT_MODEL_BASE_URL=<OpenAI兼容服务地址>
AGENT_MODEL_API_KEY=<私有密钥>
AGENT_MODEL_NAME=<模型名称>
```

资源任务启动后会固定模型快照，同一任务的五个智能体不会中途切换模型。任务记录只保存模型名称、状态和耗时，不保存端点或密钥。

课程资料需要向量检索时，还要在管理端配置可用的 Embedding 模型或启用外部向量服务。配置完成后分别执行供应商连通测试、文本模型测试和知识库检索测试，再开始正式演示。

## 9. Office 预览与本地文件

本地文件默认保存到 `WORKFORCE_FILE_LOCAL_ROOT`。该目录不能放在临时目录中，并应随 MySQL 一起备份。

需要 Office 只读预览时安装 LibreOffice，并确认：

```text
LIBREOFFICE_BIN=soffice
FILE_PREVIEW_TIMEOUT_SECONDS=120
FILE_PREVIEW_MAX_SOURCE_BYTES=104857600
```

服务器还应安装课程资料实际使用的中文字体，否则转换后的分页和换行可能变化。不使用 Office 预览时，其他课程、画像、路径和文本资源能力不受影响。

## 10. 启动验收

按以下顺序检查：

1. MySQL 和 Redis 可连接。
2. 后端健康状态为 `UP`，Flyway 最新版本为 V72。
3. 首次管理员登录成功，随后关闭管理员引导开关。
4. 管理端可以打开 AI 基座、知识库和内容安全页面。
5. 学生/教师端能够登录并读取《Java Web 应用开发》。
6. 默认文本模型连通测试成功。
7. 课程资料入库、学习画像、学习路径和五智能体资源生成主链路成功。
8. 教师审核发布后，学生能够查看资源正文和引用。
9. 浏览器控制台没有未处理异常、Vue 警告或持续失败请求。

## 11. 更新与回滚

更新前备份 MySQL 和 `WORKFORCE_FILE_LOCAL_ROOT`，记录当前 JAR 与两个 `dist` 版本。停止后端后替换三端产物，再启动 JAR；Flyway 只执行新增迁移。

数据库迁移完成后不得直接回退旧 JAR。若新版本出现问题，应按已验证的备份和回滚方案处理，不得执行 `DROP DATABASE`、`DROP TABLE`、`TRUNCATE` 或无条件批量删除。
