# AI Coding 工具使用说明

## 1. 使用范围

项目使用 Codex 辅助完成需求梳理、代码实现、测试编写、浏览器验收、文档同步和问题审查。AI 不替代项目负责人对需求、数据安全、权限和交付质量的责任。

## 2. 主要用途

- 根据开发清单定位课程、画像、路径、资源、评估和管理端缺口。
- 在现有模块边界内实现后端、学生端、教师端和运营管理端功能。
- 编写 Flyway 迁移、单元测试、集成测试和前端测试。
- 运行真实项目并检查桌面端、移动端、接口状态和浏览器控制台。
- 同步接口、表结构、状态机、部署和交付文档。

## 3. 人工与规则审查

- 根目录 `AGENTS.md` 是实现和审查的最高项目规范。
- 数据库不执行清空、重建和无条件批量删除；迁移只新增版本。
- 第三方依赖、模型和外部服务必须核对许可证、维护状态和部署影响。
- UI 修改必须经过真实浏览器桌面和移动端检查。
- 正式审查覆盖正确性、权限、数据一致性、安全、并发、性能、交互、测试和过度设计。

## 4. 验证方式

每次可交付版本执行后端全量测试、两端前端测试、两端构建和浏览器端到端流程。测试失败、审查存在未决问题或 UI 未完成实测时不提交交付版本。

## 5. 隐私与凭证

AI 不读取或输出生产凭证，不把密码、Token、模型 Key、手机号、邮箱、身份证号、学号或完整个人画像写入代码、日志、截图和交付文档。外部模型仅接收完成当前任务所需的脱敏最小上下文。

## 6. 可追溯性

功能范围以 `docs/开发规划/软件杯教育版开发清单.md` 为准；接口、数据库和状态变化分别同步到现有 API 文档、核心表结构、状态机和部署说明。自动化测试和浏览器截图作为完成证据保留在交付目录。
