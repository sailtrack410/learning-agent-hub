# 科大讯飞星火接入说明

## 1. 接入位置

教育运营管理端的“AI 基座”支持创建 `科大讯飞星火` 供应商，默认 OpenAI 兼容 Base URL 为：

```text
https://spark-api-open.xf-yun.com/v1
```

后端通过 `OpenAiCompatibleAgentModelClient` 调用兼容的 `/chat/completions` 接口。供应商、模型名称、API Password、超时和生成参数由管理端保存，不写死在源码。

## 2. 配置步骤

1. 在科大讯飞开放平台创建星火模型服务并获取 API Password。
2. 进入“AI 基座 → 供应商”，选择“科大讯飞星火”。
3. 保留默认 Base URL 或填写实际分配的兼容地址。
4. 新建文本模型，填写开放平台支持的模型名称和 API Password。
5. 执行连接测试，通过后设为默认文本模型或绑定到指定智能体。

星火兼容接口不保证提供 `/models` 列表；若自动获取模型列表失败，应按开放平台控制台显示的模型名称手工创建模型配置。

## 3. 教育用途

- 学习导师对话。
- 画像分析与学习目标归纳。
- 个性化讲解、练习和代码实操生成。
- 事实校验智能体的结构化结论生成。

课程事实仍以 RAG 检索切片为主要依据。星火模型不能替代知识库引用、权限校验和内容安全策略。

## 4. 数据与安全

- 发送前过滤真实姓名、手机号、邮箱、证件号、学号、密码、Token 和内部用户 ID。
- 只发送当前课程、知识点和任务需要的画像维度，不发送完整个人档案。
- API Password 只保存在后端受控配置中，接口响应和审计日志不返回明文。
- 连接测试只发送无个人信息的最小探测文本。

## 5. 当前效果

代码已完成供应商选项、默认兼容端点、模型配置、连接测试和智能体绑定入口。实际生成质量、耗时和费用取决于参赛团队配置的星火模型与账户额度；交付仓库不包含任何真实 API Password。
