# 软件杯教育版开发清单

> 目标：以《Java Web 应用开发》为首门示范课程，完成一条可稳定演示、可测试、可提交的个性化学习多智能体主链路。
>

## 一、范围冻结

- [x] 复用 Spring Boot、Vue 3 双端、认证、RBAC、审计、消息、文件和任务基础设施。
- [x] 复用 Agent 工作流、模型配置、RAG 入库与检索能力。

## 二、P0：比赛核心闭环

### 1. 课程与知识库

- [x] 新增课程、章节、知识点和知识点依赖关系数据模型。
- [x] 新增教师端课程列表、课程详情和知识点编排页面。
- [x] 支持课程所有者通过限时邀请链接添加协作教师，教师只能管理本人参与的课程。
- [x] 支持课程资料上传、解析、向量化、入库状态和失败重试。
- [x] 构造《Java Web 应用开发》完整课程大纲与不少于一套初始文档集。
- [x] 每条生成资源保留课程、章节、知识点和知识来源关联。

完成判定：教师可创建课程、上传资料并看到入库结果；学生检索内容能展示引用来源。

### 2. 对话式学生画像

- [x] 新增学生画像、画像维度、画像版本和画像证据数据模型。
- [x] 通过自然语言对话采集信息，不使用长表单作为主入口。
- [x] 至少形成知识基础、学习目标、掌握程度、易错点、认知风格、资源偏好、学习节奏、实践能力 8 个维度。
- [x] 展示每个维度的结论、置信度、依据和更新时间。
- [x] 学生完成练习或反馈资源后自动更新画像，并保留更新记录。
- [x] 支持学生纠正画像结论。

完成判定：一次画像对话后生成不少于 6 个有效维度；完成练习后至少一个维度发生可追溯更新。

### 3. 多智能体协同资源生成

- [x] 固化画像分析、路径规划、内容生成、练习生成、事实校验 5 个智能体角色。
- [x] 在现有 Agent DAG 中展示角色分工、输入摘要、实时内容、输出摘要和执行顺序。
- [x] 支持讲解文档、思维导图、练习题、代码实操、拓展阅读 5 类资源。
- [x] 每次生成记录所用画像版本、知识点、智能体轨迹、模型和耗时。
- [x] 支持生成进度、模型正文增量流、失败原因、重试和后台继续执行，刷新后可恢复当前增量。
- [x] 生成结果进入资源库，不只停留在聊天消息中。

完成判定：选择一个薄弱知识点后，系统可显示多智能体执行过程并产出 5 类可打开的个性化资源。

### 4. 个性化学习路径与推荐

- [x] 新增学习路径、路径节点、推荐记录和学习进度数据模型。
- [x] 根据知识点依赖、画像和掌握度生成有顺序的学习路径。
- [x] 学生端提供“今日学习”“学习路径”“推荐资源”三个核心入口。
- [x] 路径节点展示学习目标、推荐资源、预计时长、完成条件和状态。
- [x] 练习结果触发掌握度更新、资源推荐调整和路径重排。
- [x] 明确展示“为什么推荐”，避免黑盒式资源列表。

完成判定：学生完成练习后，路径或推荐内容发生合理变化，并能说明调整依据。

### 5. 学习评估

- [x] 支持单选、多选、判断、简答和代码题中的至少 3 类题型。
- [x] 记录作答、得分、知识点、错误类型、用时和尝试次数。
- [x] 生成知识点掌握度、易错点和阶段学习报告。
- [x] 评估结果回写画像，并成为下一次路径规划的输入。

完成判定：一次测验提交后可看到解析、知识点诊断和画像/路径联动结果。

## 九、固定演示流程

1. 学生与学习导师对话，生成 8 维学习画像。
2. 系统识别薄弱知识点，生成个性化学习路径。
3. 多智能体协同生成 5 类学习资源，并实时展示进度。
4. 校验智能体展示引用、置信度和校验结论。
5. 学生学习资源并完成练习，系统生成学习评估。
6. 画像与学习路径自动更新，教师端看到变化和审核记录。
